2. Approved C4 Architecture Applied

- PostgreSQL is authoritative for Module 01 domain, audit and integration state.
- Redis remains a rebuildable, non-authoritative Session Validation Projection and temporary-state store.
- The persistence inventory distinguishes Aggregate Roots, Aggregate-Owned Entities, Append-Only Records, Projections and Integration Records.
- Identity–Credential one-to-one was replaced with a lifecycle-aware one-to-many model constrained to one active current credential per approved type.
- A complete logical schema catalogue defines purpose, logical fields, constraints, protection, indexes and lifecycle requirements.
- Complete relationship, constraint, sensitive-data, retention, transaction-boundary and access-pattern catalogues were added.
- Authentication and Recovery audit records are append-only and non-deletable through application workflows.
- A PostgreSQL Transactional Outbox provides atomic event intent and at-least-once external delivery with idempotent consumers.
- Module 02 authorization data, Customer profile fields, Seller profile fields and cross-module foreign keys remain prohibited.
