# Contributing

Use Node.js 26.6.0 and pnpm 10.34.5. Create branches using `feature/`, `fix/`,
`hotfix/`, or `release/` prefixes. Commits must follow Conventional Commits.

Before opening a pull request, run `pnpm validate` and the applicable Flutter checks.
Every pull request must explain purpose, linked task, test evidence, migrations,
screenshots for UI changes, and rollback considerations. At least one approved review is required.
